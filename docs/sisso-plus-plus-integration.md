## 兼容处理

解决 `index.html`、`js/app.js`、`test/ui_smoke.test.mjs` 的冲突时，
同时保留三个模块的加载、初始化、任务取消、指标展示、导出及测试。
分类排名 CSV 可同时包含 SISSO++ 原生 loss 和辅助 RBF-SVM 指标，列顺序一致。
缺失的 SISSO++ overlap size 显示为缺失，导出为空；已有 SISSO 分数保留原精度。

额外发现并修复了三个集成问题：

1. 导入识别：原 SISSO 数据夹可能附带笔记或嵌套示例的 `sisso.json`。
   同次上传有原生 `train.dat` 时继续走原 SISSO 导入路径，避免误切换到 SISSO++。
2. 多任务后评价：仅在 SISSO++ 测试集具有明确任务映射时，按每个样本所属任务使用对应训练均值基线。
   例如合成双任务测试行的基线为 `[6.5, 4]`，不使用混合均值 `[5.25, 5.25]`。
   原生 SISSO 的后评价路径没有加入这一条件行为。
3. 标签保存：SISSO++ 的原始样本 ID 可包含逗号、空格或非 ASCII 字符。
   页面保留原始名称；项目与 Worker 的标签 ID 使用导入时的映射，确保编辑标签后能恢复项目和重新训练。

SISSO++ 自带的 SVM 预测、原生 loss 与本地可选 RBF-SVM、几何/Logistic 后评价分别保留。
辅助计算不会覆盖原始预测、原始排名或原生指标。
